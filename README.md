# PixelLab14 — лабораторная №4, вариант 14

Windows Forms, C#, .NET 9, Windows 10/11.

Откройте `PixelLab14.csproj` в Visual Studio 2022 17.14 с установленным .NET 9 SDK, затем запустите F5.

- Выберите изображение и параметры блока N×N и числа рабочих задач.
- Нажмите «Обработать». Предыдущий результат остаётся справа до успешного завершения следующей обработки.
- «Отмена» останавливает текущую операцию, не публикуя частичный результат.
- «Тест 1 / 2 / 4 / 8 потоков» записывает время в журнал и не заменяет изображение справа.
- Журнал можно увеличить мышью, перетянув горизонтальный разделитель между изображениями и журналом.

## Редактирование формы в Visual Studio

В обозревателе решений откройте папку UI. Щёлкните правой кнопкой по `MainForm.cs` → «Просмотреть конструктор» (View Designer), либо нажмите Shift+F7. Можно выделять элементы мышью, редактировать их свойства (F4), менять компоновку и события. Для добавления элементов используйте «Панель элементов» (Toolbox).

- `UI/MainForm.cs` — логика формы и обработчики событий, без ручного построения интерфейса в конструкторе.
- `UI/MainForm.Designer.cs` — стандартный метод InitializeComponent и поля элементов. Этот файл обслуживается визуальным конструктором.
- `UI/MainForm.resx` — ресурсы формы.
- `Core/PixelationProcessor.cs` — алгоритм и многопоточность.
- `Core/PixelImage.cs` — работа с пиксельным массивом.

Код снабжён русскими комментариями: `Core/PixelationProcessor.cs` — очередь и синхронизация, `Core/PixelImage.cs` — пиксельный буфер, `UI/MainForm.cs` — обработчики и асинхронные операции.
